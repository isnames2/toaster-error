# The Funniest Toaster Error Message

> ERROR 04: BREAD STUCK. I HAVE EATEN IT. THERE WILL BE NO REFUND.

## How it works

`main.py` (pure Python standard library) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is byte-identical on every run: exactly 64 characters, no trailing newline.
